# よりそい医療検索（無料公開スターター）

全国の病院・診療所・歯科診療所・薬局を、厚生労働省の医療情報ネット・オープンデータから取り込み、住所・診療科等で検索する静的サイトです。GitHub Pagesで無料公開し、GitHub Actionsで毎日データの更新有無を確認します。

## 重要な制度上の注意

- 医療情報ネットの施設データは施設名・住所・電話・診療科・診療時間等を掲載するためのものです。
- 厚労省の「医療扶助オンライン資格確認参加医療機関・薬局リスト」は、オンライン資格確認の利用設定機関の一覧です。生活保護法上の指定医療機関一覧と同一ではありません。
- このスターターは参加リストとの照合結果を別項目として表示し、生活保護法上の指定状況は公式指定情報を別途取得できるまでは「未確認」とします。「未確認」を「非対応」と読み替えないでください。
- 医療情報ネットの公開データは定期更新であり、毎日新しい施設データが出るわけではありません。自動処理は毎日公開元を確認し、最新公開分を取り込みます。

## 公開手順（無料）

1. GitHubでアカウントを作り、新しい **Public repository**（例 `yorisoi-medical-search`）を作成。
2. このフォルダ内のファイルをすべてリポジトリ直下にアップロードして `main` ブランチへコミット。
3. GitHubの **Settings → Pages** を開き、Build and deployment の Source を **Deploy from a branch**、Branch を **main**、Folder を **/(root)** にして Save。
4. **Actions** タブで `Update official medical data` を開き、`Run workflow` を1回実行。初回データを生成します。
5. Pagesに表示されたURL（`https://ユーザー名.github.io/リポジトリ名/`）で公開を確認。

## ローカルで初回データを作る場合

```bash
python -m pip install -r requirements.txt
python scripts/update_data.py
```

## 注意点・改善が必要な点

- 厚労省が公開するCSV ZIPの列名やURL構成が変更されると、取り込みスクリプトの調整が必要です。Actionsの実行結果を確認してください。
- 都道府県・自治体ごとの生活保護法上の指定医療機関名簿は、公開形式・公開場所が統一されていません。このため全国の指定状況を完全自動で保証する機能は未実装です。全国網羅を名乗らず、公式の指定名簿を自治体別に収集・検証できた範囲だけ「指定確認済み」にする必要があります。
- 地図リンクはGoogleマップ検索を開きます。外部地図APIキーは不要です。
- GitHub PagesとGitHub Actionsは無料枠内での利用を想定しています。大容量データの頻繁なコミット等で制限に達する可能性があります。

## 生活保護法上の指定状況の自動照合（追加）

`data/designation_sources.json` に登録した自治体の公式ページから、XLSX/CSV/ZIP内のXLSX・CSVを毎日取得します。医療機関コード完全一致を優先し、コードがない場合は名称と住所が一意に一致したときだけ「指定確認済み」とします。XLSXは先頭数行から見出し行を推定し、PDFは表として抽出できた行のみ照合します。スキャンPDFや自由形式のPDFは自動確定しません。

現時点で登録済みの指定名簿ページは北海道、愛知県、横浜市、京都市、沖縄県、兵庫県、三重県、福岡市、富山県、那覇市、石川県の12ページです。これは11都道府県の一部区域に限られ、各県内の指定都市・中核市等の独自管轄区域も残っています。`designation_coverage` と `designation_sources_audit` に取得件数・失敗・対象範囲を出力します。未登録地域は必ず「未確認」です。

### 全国網羅にするための残作業

- 47都道府県の県所管区域について、指定名簿の公式ページとファイルを登録・検証する。
- 政令指定都市・中核市等、独自に指定・公表する自治体を管轄別に追加する（県名簿から除外される自治体を特に確認）。
- PDF・HTMLしかない自治体は専用パーサーを作り、原本リンク・基準日・抽出件数を監査する。
- 施設コード体系が異なる場合は、厚生局の保険医療機関コード等との対応表を検証する。

このため、現在の実装は「登録済み公式名簿の自動照合」であり、全国完全網羅を保証するものではありません。生活保護法49条の指定主体・制度上の根拠は法令を参照してください。

## 全国対応の範囲（重要）

- 医療機関の検索データは、厚生労働省「医療情報ネット」の全国オープンデータを基礎に取得します。したがって、検索UIは全国の住所・地域を対象に検索します。
- 生活保護法上の指定状況は、都道府県・政令指定都市・中核市等がそれぞれ公表する指定名簿を取得できた範囲だけを「確認済み」とします。現状、全自治体の名簿が接続済みではなく、法的な意味での全国完全照合は未達です。
- 指定権者は所在地により異なり、自治体名簿に載っていないことだけで「指定なし」と判定してはいけません。必ず `unknown`（未確認）として扱います。
- 国が開設した病院等は地方厚生局が所管するため、自治体名簿とは別の公式一覧が必要です。
- 全国完全照合を名乗るには、全都道府県・指定都市・中核市等の管轄区域を漏れなく登録し、各名簿の更新日・取得件数・照合精度を検証する必要があります。

このため、本バージョンは「全国の医療機関検索＋一部地域の生活保護法指定状況照合」です。「全国すべての施設の指定状況を確認できる」と案内してはいけません。


## ブラウザ側の自動照合（追加）

- データ更新処理は自治体公式ページから取得した指定名簿レコードを `designation_index` として `data/facilities.json` に保存します。
- 利用者がページを開くと、ブラウザ内の JavaScript が全国施設データと指定名簿データを自動照合します。
- 医療機関コード完全一致を優先し、次に施設名・住所の完全一致を確認します。複数候補や名称のみ一致は「候補・要確認」、一致しない場合は「未確認」です。
- ブラウザから各自治体サイトを直接スクレイピングする方式ではありません。自治体サイトのCORS制限や形式差があるため、GitHub Actionsが公式名簿を取得し、ブラウザは取得済みの名簿データを照合します。
- 現在登録済みの公式名簿は一部自治体に限られるため、全国の指定状況がすべて照合されるわけではありません。名簿が登録されていない地域は「未確認」のままです。


## 全国の未公開データを補完する運用（追加）

公開名簿が見つからない地域を「指定なし」と推定しない。次の順番で補完する。

1. 自治体公式サイトの指定医療機関一覧・告示・公報・オープンデータを調査する。
2. 公開情報が不足する場合は `templates/municipality_inquiry_email.md` を使い、担当部署へ所管範囲、最新名簿、基準日、更新頻度、公報の掲載先を照会する。
3. 通常照会で入手できない場合は、自治体の情報公開制度を確認し、`templates/public_information_request.md` の対象文書例を参考に請求を検討する。
4. 調査・照会の進捗は `data/authority_followup.csv` に記録する。追加の指定権者は `data/municipal_authorities_template.csv` に登録する。
5. 回答文書・公報・名簿は出典URL、取得日、基準日、対象区域、ファイル名とともに保存し、照合データに反映する。
6. 「未回答」「資料不存在」「非公開」「対象外」「名簿未更新」は別々に記録し、いずれも指定なしとは判定しない。

### 大切な運用上の制限

- 自治体へのメール送信・情報公開請求は、このリポジトリから自動送信しない。担当者が宛先・文面・請求手数料等を確認して実行する。無断の大量送信や不適切な請求を避けるためである。
- 47都道府県の行は調査管理用の初期台帳であり、各都道府県が全域の指定権者であることを意味しない。政令指定都市等の権限・所管区域は自治体ごとに確認し、別レコードとして登録する。
- 公式名簿や公報の取得・解析が自動化できない自治体は、回答資料を人が確認して登録する。
- 全国完全網羅を名乗るには、全指定権者の所管範囲を確定し、全区域で最新の公式根拠を確認し、未取得区域がゼロであることを監査する必要がある。
